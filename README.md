# agape-coordination

**Coordination patterns and experiments for low-cost cooperation inside the OpenRoot lattice.**

## What this is
Focused work on coordination mechanisms that support the broader Agape and UNE systems.

## Role in the Lattice
Supports the cooperation layer by exploring practical coordination structures.

## Bigger Picture
Part of the effort to make high-synergy cooperation cheaper than extraction or fragmentation, especially under offline and low-resource conditions.

## Current Status
Experimental / supporting spoke.
